# Duration

The Duration renderer detects **ISO 8601 durations** (e.g. `P7DT2H`) as part of the
component's ISO 8601-compliant date handling. It shows a humanized summary (e.g.
"7 days, 2 hours"), and an interactive **end-datetime calculator**: enter a start
datetime and the component computes and displays the corresponding end datetime using
calendar-accurate Temporal arithmetic.

## Supported Formats

ISO 8601 duration notation (`PnYnMnDTnHnMnS`):

- Date + time: `P7DT2H`, `P1Y2M3DT4H5M6S`
- Week form: `P2W`
- Time only: `PT2H30M`, `PT1.5H`

## End-Datetime Calculator

The renderer displays the duration breakdown (years/months/days/hours/…) in the data table
and an interactive calculator. It expands by default so the calculator is immediately visible:
enter a start datetime and press **Calculate end datetime** to view the result.
